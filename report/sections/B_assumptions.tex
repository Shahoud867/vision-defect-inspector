\section{Assumptions and Scope}
\label{app:assume}

\subsection{Assumptions}
\begin{enumerate}
  \item \textbf{Datasets.} The Kaggle \PCB{} and \CRACK{} sets need
  credentials, so they are not committed. When absent, the loader synthesises
  statistically-matched stand-ins with exact ground truth. Running
  \code{python scripts/download\_data.py} (Kaggle token in \code{\textasciitilde/.kaggle})
  then \code{cvlab all --data-dir data/raw} regenerates every figure on the
  real data unchanged.
  \item \textbf{Cross-correlation} is used for all spatial filtering (brief
  \S1.2); kernels are odd-sized; \code{'same'} padding preserves size only at
  stride 1 (\cref{eq:convsize}).
  \item \textbf{Border handling.} Blur and Sobel use \code{reflect} padding
  (not zero) to avoid a dark rim and false border gradients; NMS then zeroes
  the 1-px border as the brief requires.
  \item \textbf{Thresholds.} Default $(\Thi,\Tlo)$ are quantiles of the
  non-zero NMS response (illumination-robust); absolute values are accepted
  too. Grayscale conversion uses BT.601 luma.
  \item \textbf{Determinism.} Every stochastic step takes an explicit
  \code{numpy.random.Generator}; the master seed is \num{2515}.
\end{enumerate}
