# Report

Two documents are built from the same modular sources:

| File | Class | Purpose |
|------|-------|---------|
| `main.tex` → `report.pdf` | `IEEEtran` (conference, 2-col) | **The assessed submission** — capped at 4 pages: methods, ablations, quantitative comparisons, scale-space causality, failure analysis, theoretical answers. |
| `supplementary.tex` → `supplementary.pdf` | `article` | Portfolio companion — title page, ToC, lists of figures/tables, full derivations (Appendix A), assumptions & scope (Appendix B), complete listings. Not part of the 4-page limit. |

## Layout

```
report/
├── main.tex              # 4-page IEEE report
├── supplementary.tex     # extended companion
├── preamble.tex          # shared packages + macros
├── references.bib        # BibTeX (IEEEtran style)
├── sections/             # one file per section (01_… 06_…, A_…, B_…)
├── figures/              # optional extra figures; output_images/ is also on graphicspath
├── latexmkrc             # latexmk config (build/ out dir, bibtex)
└── Makefile
```

Figures are pulled from `../output_images/` (regenerate with `cvlab all` from
the repo root). `\graphicspath` includes both `figures/` and `../output_images/`.

## Build

**Local (TeX Live ≥ 2021 or MiKTeX):**

```bash
cd report
make            # report.pdf + supplementary.pdf  (via latexmk)
make report     # just the 4-page submission
make watch      # live rebuild
make clean
```

Manual fallback:

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

**No LaTeX installed?**

- **Overleaf** — upload the `report/` folder *and* the `output_images/` folder
  (place `output_images/` next to `report/`), set `main.tex` as the main
  document, compiler = pdfLaTeX.
- **GitHub Actions** — `.github/workflows/report.yml` compiles both PDFs on
  every push and uploads them as build artifacts.
- **Docker** — `docker run --rm -v "$PWD":/w -w /w/report texlive/texlive make`.

## Keeping numbers in sync

Every figure in the report is regenerated by `cvlab all` (seed `2515`).
`python scripts/report_numbers.py` prints all quantitative values used in the
prose/tables straight from `results/*.json`, so they can be re-checked after a
re-run.
